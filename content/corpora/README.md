# R6 authored draft corpus

`hanzi-starter-draft-v1.json` binds ten new R6 package versions and twenty distinct
characters. It reuses the existing authored R5 teaching and source attribution
without changing those original packages or their frozen lesson behavior.

Every human content/audio/device review remains pending. This is a draft authoring
batch, not a reviewed or released starter library. The 1,600-character requirement
is unchanged. No file here is imported into the active family database by its
presence in the repository.

The fixed source generator is `scripts/build-corpus-fixtures.py`. The related
test oracles document their mechanical limits separately.
